哲人石CRM

连接团队服务端。账号和密码只在 CRM 登录页输入，不在客户端设置中保存。

隧道入口固定为 http://127.0.0.1:18088；占用时不会换端口或结束其他进程。外部隧道请自行确认来源。

客户端管理 SSH

仅使用 Windows 内置 OpenSSH，严格主机密钥校验，BatchMode 公钥认证；不弹密码框，不启用 agent，不自动接受新主机密钥。加密私钥需另行选择可用的个人认证方案，客户端不保存口令。

HTTPS

修改入口会切换服务端及 Web 存储身份；不会删除旧数据。同一用户同时只运行一个客户端。退出前保存表单，服务端会话可能过期。
