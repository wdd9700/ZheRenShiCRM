六列资源导入

上传 → 预览和消歧 → 显式确认 → 查看结果。创建企业、联系人与需求线索，不自动创建商机。

1. 上传CSV

UTF-8（可含BOM），最多1MiB / 500行。六列表头可重排；产品、需求、联系方式原文及来源会保存在需求线索。重复资料不覆盖既有数据。

表头：序号、姓名、公司名称、联系方式、公司产品、服务、需要的产品、服务（含逗号的标题请用CSV引号）。

管理员导入（本轮仅合成数据）：创建企业/联系人将对现有Sales User角色开放，包括姓名、企业及解析后的联系方式。私域原文只保存在Lead并不使共享联系人变为私域。本页尚不支持仅建立私域Lead的模式；不接受共享请勿导入。

请选择CSV文件。

2. 逐行预览与消歧

已有企业或联系人须显式选择。联系人必须已经关联该企业；关联不明请先在原生CRM整理，再重新预览。未选择/错误行会失败，其余行仍可导入。同批完全相同的联系人资料复用本批新建联系人。

3. 导入结果

失败CSV含原六列、来源行号及原因；为防电子表格公式执行，危险前缀会增加单引号。它是报告，修正后请使用原六列表头重新上传。请求中断请重新预览后重试，不要假定整批成功或失败。
